# 15-mortgage（房贷月供）

Mortgage — 等额本息月供与逐期本金利息拆分

## 启动

```bash
docker compose up --build
```

| 入口 | 地址 |
| --- | --- |
| 前端 | http://localhost:4400 |
| API | http://localhost:9400 |

## 主链

贷额期限利率 → 等额本息还款表 → 利息合计

## 单期逾期罚息

规则页维护罚息规则（免罚天数、日罚率%/日、启用）；试算台可附逾期期序号与天数，命中启用规则时罚息 = 该期月供 × 日罚率 × 超出免罚的天数，回包含原月供、罚息与含罚合计；写入的罚息随记录快照保存，事后调整规则不影响旧记录。

## 技术栈

Python 3.12 + FastAPI + SQLite；Vue 3 + Vite + Nginx。
